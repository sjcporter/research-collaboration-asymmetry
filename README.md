# Research Collaboration Asymmetry

Interactive site profiling the University of Bath's institutional co-authorship network, 2020 – mid-2026 (2026 partial), with reciprocal-rank asymmetry as the primary lens.

Live site: **https://sjcporter.github.io/research-collaboration-asymmetry/**

## What's here

- `src/` — Observable Framework pages (`index.md`, `partners.md`, `country.md`, `field.md`, `type.md`, `methodology.md`)
- `src/data/bath_collaborators.parquet` — ~400 KB; one row per Bath partner with reciprocal ranks, dominant FoR, partner type, country, etc. Bundled with the site and loaded into DuckDB-WASM in the browser. No server round-trips at view time.
- `src/components/duck.js` — small helper for materialising Arrow tables to plain JS objects + a fixed FoR colour palette.
- `.github/workflows/deploy.yml` — auto-deploys to GitHub Pages on push to `main`.

## Data lineage

The parquet is generated by the analysis repo (`institutional-collaboration`):

1. `queries/build_collab_pairs.sql` builds a global directed institutional pairs table (publications 2020 – mid-2026 (2026 partial)).
2. `queries/reciprocal_rank.sql` produces a focal-institution view with reciprocal ranks.
3. `queries/focal_partner_dominant_for.sql` adds the modal first-level FoR per partner.
4. `scripts/add_dominant_for.py` joins (1)–(3) into the parquet shipped here.

## Run locally

```bash
npm install
npm run dev        # http://127.0.0.1:3000
npm run build      # static site → ./dist
```

Requires Node ≥ 20.6.
